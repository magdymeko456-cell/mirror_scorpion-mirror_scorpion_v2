# 🦂 Mirror Scorpion - ميرور سكربيون

**حيث تُصنع البدايات** | Where Beginnings Are Made

## الميزات

1. **ترجمة نصية** - 100 لغة مع مايك ونطق ونسخ ومشاركة
2. **حوار مترجم** - محادثة ثنائية فورية مع تبديل اللغات
3. **مستندات وعدسة** - ترجمة الصور والملفات مع Google Lens
4. **قصص وإلهام** - أحاديث قدسية، قصص الأنبياء، أسباب النزول، إلهام ذكي
5. **ألعاب 3D** - شطرنج + روبيك
6. **إعدادات** - Pro/Premium، أصوات، مظهر

## التقنيات
- Flutter 3.24.3 | Dart 3.2+
- Google MLKit (Text Recognition)
- MyMemory Translation API
- Flutter TTS (4 أصوات: سيف، سلمى، سما، سارة)
- الفقاعة العائمة (System Overlay)
- تشفير 360° (ProGuard + Obfuscation)
- تشفير التفعيل (AES-XOR)
